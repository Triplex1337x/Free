# Claude в Telegram

Бот для Telegram, в котором отвечает Claude. Пишешь ему, как в обычный чат, и он отвечает. Бот помнит, о чём шла речь, пока ты не напишешь `/reset`.

## Какой режим выбрать

| | `cli` (по умолчанию) | `api` |
|---|---|---|
| Чем платишь | твоей подпиской Pro/Max | API-ключом, отдельно и по факту |
| Где работает | на твоём компьютере, пока он включён | где угодно, хоть на сервере 24/7 |
| Кому отвечает | только тебе | кому разрешишь |
| Что нужно | установленный Claude Code | ключ с console.anthropic.com |

**Почему подписки мало для «настоящего» бота.** Подписка покрывает приложения Claude (сайт, десктоп, Claude Code), и их лимиты рассчитаны на одного человека. Режим `cli` просто запускает твой Claude Code, поэтому работает по подписке. Если бот должен работать на сервере круглосуточно или отвечать другим людям, нужен API: он оплачивается отдельно, по количеству текста.

## Установка (5 минут)

1. **Создай бота.** Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя. Он пришлёт токен вида `123456:ABC...`.
   Токен никому не отправляй, даже в чат с Claude. Он нужен только в файле `.env` на твоём компьютере.

2. **Скачай проект и поставь зависимости** (Python 3.10+):
   ```bash
   git clone https://github.com/triplex1337x/free.git
   cd free
   python -m venv .venv
   # Windows:      .venv\Scripts\activate
   # macOS/Linux:  source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. **Настрой.** Скопируй `.env.example` в `.env` и впиши `TELEGRAM_BOT_TOKEN`.

4. **Для режима `cli`:** установи Claude Code и один раз войди в аккаунт:
   ```bash
   claude        # откроется браузер для входа, потом выйди: /exit
   ```

5. **Запусти бота и узнай свой ID:**
   ```bash
   python bot.py
   ```
   Напиши боту в Telegram `/id`, впиши число в `ALLOWED_USER_IDS` в `.env` и перезапусти бота (Ctrl+C, потом снова `python bot.py`).

Готово, теперь пиши боту.

## Команды бота

- `/start` — приветствие
- `/reset` — забыть разговор и начать заново
- `/id` — показать твой Telegram ID

## Настройки в `.env`

- `CLAUDE_BACKEND` — `cli` или `api`.
- `ALLOWED_USER_IDS` — кому бот отвечает (ID через запятую). Остальным он не отвечает, чтобы чужие люди не тратили твои лимиты.
- `CLAUDE_MODEL` — модель. В режиме `cli`: `opus`, `sonnet`, `haiku`. В режиме `api`: полное имя, например `claude-opus-5-5`. Пусто = по умолчанию.
- `SYSTEM_PROMPT` — характер бота, например «Отвечай как пират».
- `ANTHROPIC_API_KEY` — только для режима `api`.

## Безопасность

- В режиме `cli` у Claude **отключены все инструменты**: он только разговаривает и не может читать файлы или запускать команды на компьютере.
- `.env` с токенами уже добавлен в `.gitignore`, поэтому в GitHub он не попадёт.
- Если токен бота утёк, отзови его: @BotFather → `/revoke`.

## Частые проблемы

- **«Не нашёл команду 'claude'».** Проверь `claude --version`. Если команда не находится, впиши полный путь в `CLAUDE_CLI_PATH` в `.env`.
- **«Claude Code вернул ошибку».** Запусти `claude` в терминале и войди в аккаунт.
- **Бот молчит.** Проверь, что `python bot.py` запущен и в консоли нет ошибок.
