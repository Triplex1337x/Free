# Claude отвечает людям в Telegram по твоей команде

Ты пишешь в своё **«Избранное»** в Telegram, и Claude отправляет сообщение нужному человеку **с твоего аккаунта**. Получатель видит обычное сообщение от тебя.

## Как пользоваться

Всё пишется в «Избранное» (Saved Messages):

| Ты пишешь | Что происходит |
|---|---|
| `клод, напиши Артёму: скинь ДЗ пж` | Артёму сразу уходит «скинь ДЗ пж» |
| `клод, ответь Артёму, что буду в 5, и извинись` | Claude читает вашу переписку, пишет ответ в твоём стиле и показывает черновик |
| `+` или `да` | отправить черновик |
| `-` или `нет` | отменить черновик |
| `удали` | удалить последнее отправленное сообщение у обоих |

Команда начинается со слова `клод`, `claude` или `!`. Остальные заметки в «Избранном» ассистент не трогает.
Имена можно писать как угодно: «Артёму», «Артему», «артем». Если подходят несколько человек, Claude переспросит.

## Установка

Нужны Python 3.10+ и Claude Code, в котором ты вошёл в аккаунт (команда `claude`). Работает по твоей подписке, **API-ключ не нужен**.

1. **Получи ключи приложения Telegram.** Зайди на [my.telegram.org](https://my.telegram.org), выбери **API development tools** и создай приложение (название любое). Скопируй `api_id` и `api_hash`.

2. **Скачай проект и поставь зависимости:**
   ```bash
   git clone -b claude/telegram-message-artem-tp0dsn https://github.com/triplex1337x/free.git
   cd free
   pip install -r requirements.txt
   ```

3. **Настрой.** Скопируй `.env.example` в `.env` и впиши `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.

4. **Запусти:**
   ```bash
   python assistant.py
   ```
   При первом запуске скрипт спросит номер телефона и код, который придёт в Telegram (и облачный пароль, если он есть). Это вход в твой аккаунт, больше спрашивать не будет.

Когда в «Избранном» появится «🤖 Я на связи», можно пользоваться. Ассистент работает, пока на компьютере открыт `python assistant.py`.

## Важно

- **Файл `telegram.session` = полный доступ к твоему Telegram.** Никому его не отправляй и не заливай в интернет (он уже в `.gitignore`). Если он утёк: Telegram → Настройки → Устройства → завершить чужой сеанс.
- Ключи из `.env` тоже никому не показывай, даже Claude в чате.
- Чтобы найти получателя, Claude видит названия твоих последних чатов. Когда он сочиняет ответ, он видит последние 20 сообщений этого чата. Больше ничего.
- Не используй ассистента для рассылок и спама: Telegram банит за такое аккаунты. Отвечать по одному сообщению по своей команде — нормально.

## Настройки в `.env`

- `CONFIRM`: `compose` (по умолчанию, подтверждать только то, что сочинил Claude), `always` (подтверждать всё) или `never` (не подтверждать ничего).
- `TRIGGERS`: слова, с которых начинается команда.
- `CLAUDE_MODEL`: `opus`, `sonnet` или `haiku`. `haiku` отвечает быстрее всех.

## Частые проблемы

- **«не нашёл команду claude».** Проверь `claude --version`. Если не работает, впиши полный путь в `CLAUDE_CLI_PATH`.
- **«Claude Code вернул ошибку».** Запусти `claude` в терминале и войди в аккаунт.
- **Ничего не происходит.** Проверь, что `python assistant.py` запущен и команда начинается с `клод`.
