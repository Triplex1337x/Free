# Личный сайт-резюме

Одностраничный сайт без сборки и зависимостей: светлая и тёмная тема, анимации, адаптив под телефон и кнопка «Скачать PDF» (печатная версия резюме).

## Как заполнить своими данными

Вся информация лежит в **`data.js`**: имя, роль, «обо мне», навыки, опыт, проекты, образование, контакты. Меняй текст в кавычках, сохраняй и обновляй страницу. Остальные файлы трогать не нужно.

- **Окно с кодом на первом экране:** строки меняются в разделе `card`.
- **Убрать раздел:** сделай его пустым, например `projects: []`, и он исчезнет вместе с пунктом меню.
- **Уровень навыка:** `level` от 1 до 5. Без `level` навык показывается «таблеткой».

## Как посмотреть

Просто открой `index.html` в браузере (двойной клик).

## Где сайт в интернете

Сайт опубликован через GitHub Pages: **https://triplex1337x.github.io/Free/**

Его файлы лежат в ветке `gh-pages`. Чтобы обновить сайт, поменяй файлы в этой папке и скопируй их в ветку `gh-pages`: через минуту GitHub выложит новую версию.

## Файлы

| Файл | Что внутри |
|---|---|
| `data.js` | все твои данные |
| `index.html` | структура страницы |
| `styles.css` | оформление, темы, печать |
| `main.js` | отрисовка данных и анимации |
