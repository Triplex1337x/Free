# Chrono-Drill Simulator — плейс для Roblox

Готовая игра по ТЗ «Chrono-Drill Simulator 1.0». Всё — мир, 5 островов-биомов, 120 питомцев,
20 буров, 20 рюкзаков, 15 яиц, NPC, интерфейс, анимации и эффекты — собирается **кодом из примитивов
Roblox**, поэтому плейсу не нужны загруженные меши, текстуры или чужие ассеты.

## Как запустить

1. Откройте `ChronoDrill.rbxlx` в Roblox Studio (File → Open from File).
2. Нажмите **Play**. Сервер за 3–5 секунд соберёт мир и модели (в режиме редактирования Workspace пустой — так и задумано).
3. Для сохранений: опубликуйте плейс и включите *Game Settings → Security → Enable Studio Access to API Services*.
   Без этого игра работает, но прогресс не сохраняется (в Output будет предупреждение).
4. При публикации: *Game Settings → Places → Server Size = 10* (ТЗ: ровно 10 игроков).

### Панель разработчика (F2)
В Studio, у владельца плейса и у админов группы (ранг 254+) — клавиша **F2** или красная кнопка со щитом
(на телефоне — рядом с меню). Слева выбираешь цель: **себя**, **любого игрока на сервере** или **всех сразу**.
Вкладки: **Ресурсы** (монеты, ребёрсы, осколки, бусты, «открыть всё», своё число), **Питомцы** (поиск по всем
питомцам, улучшение, уровень, количество), **Телепорт** (база/шахта любого яруса, к игроку, призвать к себе),
**Пассы** (выдать/снять любой геймпасс), **События** (x2–x10 монеты/урон/удача на 5–60 минут для всего сервера,
Золотая лихорадка, вайп шахт, время суток, объявление) и **Консоль** (ввод любых команд).
F3 — старая текстовая консоль. Те же команды пишутся в чат через `!` (`!coins 1m`, `!coins 1m @Ник`, `!event coins 2 15`).
Дать доступ ещё кому-то: `EXTRA_ADMINS` в `ServerScriptService/Managers/AdminCommands`.

| Команда | Что делает |
|---|---|
| `help` | список всех команд |
| `coins 5m` / `setcoins 0` | добавить / установить монеты (k, m, b, t, q) |
| `drill max`, `drill 6` / `pack 4` / `max` | выдать буры / рюкзаки до номера / открыть вообще всё |
| `pet Worm 3 15 5` | питомец: id или имя, улучшение 0–5, уровень, количество (`pets` — список id) |
| `petlevel 30`, `clearpets` | уровень надетым питомцам, удалить всех |
| `unlock 5`, `tp hub 3`, `tp mine 2`, `goto @Ник`, `bring @Ник` | ярусы и телепорты |
| `boosts 5`, `seeds 3`, `shards 20`, `rebirths 2`, `addrebirths 5` | предметы и прогресс |
| `pass VIP on`, `pass all off`, `passes` | выдать / снять геймпассы, список ключей |
| `event coins 2 15`, `event luck 5 30`, `event stop` | событие на весь сервер: множитель и минуты |
| `quests`, `newquests`, `story 5` | выполнить / перевыдать задания, перейти к сюжетному квесту |
| `daily`, `wheel`, `tutorial` | сбросить таймеры наград, пройти обучение заново |
| `resetmine`, `goldrush 120`, `time 20` | вайп шахт, Золотая лихорадка, время суток |
| `speed 60`, `info`, `players`, `announce текст`, `wipe` | разное |

Любую команду можно применить к другому игроку — `@ник` в конце, ко всем — `@all`.

### Геймпассы (магазин «Донат»)
Список и цены — `ReplicatedStorage/Configs/GamepassesData`. Чтобы пассы продавались: Creator Hub → твоя игра →
**Monetization → Passes → Create a Pass**, скопируй ID и впиши в поле `Id` нужного пасса (вместо `0`).
Цену на сайте поставь такую же, как в `Price` (она только показывается в меню). Пока `Id = 0`, кнопка покупки
пишет, что пасс не настроен, а выдать его можно из панели F2 (для теста).

| Пасс | Эффект |
|---|---|
| VIP | x1.25 монет и урона, +1 слот питомца, VIP-тег над головой |
| x2 Монеты / x2 Урон | продажа / урон бура в 2 раза больше |
| Удача | x2 шанс редких, легендарных и мифических питомцев |
| Открытие x8 | кнопка «x8» в окне яйца |
| +2 питомца | на 2 надетых питомца больше (одновременно) |
| +100 мест | инвентарь питомцев больше на 100 мест |
| x2 Рюкзак | вместимость рюкзака x2 |
| Автооткрытие | кнопка «Авто» в окне яйца: яйца открываются сами, пока хватает монет |
| Бесконечный рюкзак (3999 R$, эксклюзив) | рюкзак никогда не заполняется |
| Быстрые ноги | +30% скорости бега |
| Слот инкубатора | 3-й слот для семян |

### Управление
ЛКМ / зажать экран / R2 — бурить · **T** или кнопка «НА БАЗУ» — мгновенный телепорт на базу ·
**P** питомцы · **I** индекс · **B** предметы · **Q** задания · **K** статистика · **J** награды · **L** колесо · **M** миры · **R** ребёрс ·
магазины буров и рюкзаков — домики на базе: зайди в светящуюся зону перед дверью · продажа — встань в золотой круг
у «Золотого обменника» · **E** — яйца, инкубатор, NPC · **F2** — панель разработчика.

## Как поставить наши звуки и музыку

В папке `SFX/` — 19 звуков и 3 зацикленных трека (`Music_Hub`, `Music_Mine`, `Music_Deep`), всё синтезировано
с нуля (`tools/make_sfx.py`), без чужих сэмплов.

1. В Studio: **View → Asset Manager → Bulk Import** и выбери все `.ogg` из папки `SFX`. Roblox проверит и загрузит их
   (бесплатно, обычно пара минут).
2. В Asset Manager открой **Audio**, перетащи каждый звук в Explorer в папку **ReplicatedStorage → CustomSounds**.
   Имя объекта Sound должно совпадать с именем файла (`BlockBreak`, `Coins`, `Music_Hub`…). Если имя отличается, переименуй.
3. Опубликуй плейс. Игра сама возьмёт звуки и музыку из `CustomSounds`, вписывать ID никуда не нужно.

Можно и вручную: скопировать ID звука (ПКМ → Copy ID) и вписать в `ReplicatedStorage/Configs/SoundsData`
как `Id = "rbxassetid://123456"`. Пока свои звуки не загружены, играют мягкие встроенные звуки Roblox, а музыки нет.
Громкость музыки и звуков — в меню **Настройки**.

## Как включить новые цветные иконки

В папке `Icons/` лежит набор из 36 цветных иконок: `ChronoDrill_Icons.png` — атлас 1024×1024 (7×7 ячеек по 146 px),
`png/` — каждая иконка отдельно 256×256, `svg/` — исходники. Игре нужен только атлас: **одна картинка, один ID**.

1. В Studio: **View → Asset Manager → Bulk Import** и выбери `Icons/ChronoDrill_Icons.png`.
2. В Asset Manager нажми ПКМ по картинке → **Copy Asset ID**.
3. Открой `ReplicatedStorage → Configs → IconAtlas` и впиши ID: `Id = "rbxassetid://1234567890",` (можно просто число).
4. Нажми Play: все иконки меню, окон, счётчиков, наград и магазинов станут цветными.

Пока `Id` пустой, игра рисует прежние векторные иконки, поэтому ничего не ломается. Крестик, галочка, плюс и стрелка
остаются белыми векторными: так они лучше читаются на цветных кнопках.

Если картинка загружена как **декаль** через сайт, у неё другой ID (ID декали ≠ ID картинки), и скрипт её не покажет.
Вставь ID декали в свойство Image любого ImageLabel в Studio: Studio сам заменит его на ID картинки. Скопируй
получившееся число в `IconAtlas`.

Перерисовать или добавить иконки: правь `tools/make_icons.py`, затем запусти `python3 tools/make_icons.py` и
`node tools/render_icons.js` (нужен Playwright с Chromium). Раскладку в `Configs/IconAtlas` скрипт обновит сам.

## Версия 1.8 — новое окно яиц, автооткрытие, автоудаление, мультиудаление

- **Геймпассы**: «Автопродажа» убрана; добавлены «Автооткрытие» и эксклюзивный «Бесконечный рюкзак» за 3999 R$.

## Версия 1.7 — порталы, шайни, инвентарь, 30 буров и рюкзаков

- **Порталы** — каменные арки из гранёных блоков с закрученной светящейся воронкой, искрами и объёмным названием яруса.
- **Вход в шахту** — вместо зелёной таблички каменная арка с большими объёмными буквами яруса; Drill-Bot отошёл в сторону.
- **Ежедневная награда** — раз в 24 часа (было 20).
- **Инкубатор на холме**: ступенчатый подиум, столб света, вращающееся кольцо и объёмная надпись — видно издалека.
- **Яйца на сцене** с пологими ступенями; название и цена — на табличке у подставки, ничего не висит в воздухе.
- **30 буров и 30 рюкзаков** (по 6 на ярус). Экономика пересчитана: первый ярус ≈ 1.5 часа, вся игра без ребёрсов ≈ 20 часов
  (было ≈ 10). Топовый бур каждого яруса прежний, шлюзы работают как раньше.
- **Шайни-питомцы**: 1 из 250 питомцев из яйца выпадает шайни (удача увеличивает шанс, максимум x4) — сила x5.6
  (чуть сильнее золотого), глянец, переливающиеся искры, надпись над питомцем и отдельная анимация выпадения. Улучшать нельзя.
- **Инвентарь питомцев ограничен**: 50 мест, кнопка «+» в окне «Питомцы» докупает +10 мест за монеты (до 250),
  геймпасс «+100 мест».
- **Баг «надето 3 из 3, а видно двух»**: после телепорта на другой остров (в т.ч. после ребёрса) питомец мог «потеряться»
  по пути — теперь он сразу переносится к игроку. На карточке стака видно, сколько одинаковых питомцев надето (x2).
  Ребёрс питомцев не снимает (проверено тестом).
- **Купленные геймпассы** — значками в углу экрана (наведи — подсказка).
- **Зоны продажи и покупки** стоят на своих подиумах — больше не сливаются с землёй; надписи «ЗОНА…» убраны.
- **Текстуры**: блоки шахты снова с родными текстурами (земля, камень, руда), скалы и камни — сланец, дорожки — булыжник,
  площадь — мрамор, деревья и дома — дерево. Земля и листва остались гладкими.

## Версия 1.6 — донат, панель разработчика, мягкая графика, зона продажи

- **Баг «прыгнул в чужую яму — прошёл ярус»** исправлен: следующий ярус открывается, только когда ты *сам* сломал

- **Таблицы лидеров:** три деревянные доски на базе каждого яруса — «Топ по блокам», «Топ по ребёрсам», «Топ по яйцам». Глобальные (OrderedDataStore, обновление раз в 90 секунд); в Studio без доступа к API доски показывают игроков на сервере.

Перед дверью — светящаяся **зона покупки**: окно магазина открывается само, когда заходишь в зону, и закрывается, когда выходишь. Купить можно только стоя в зоне.   - Новые цены и прочность: первый ярус ≈ 50–60 минут, вся игра до последнего бура ≈ 10 часов (до ребёрсов).

  - Ауры эксклюзивов и петов из семян ослаблены.

| ProfileService | Свой DataManager на DataStoreService с сессионной блокировкой и автосейвом. | Без сторонних модулей; поведение то же (защита от дюпа, сейв при выходе/закрытии). |

## Пересборка из исходников

```
python3 tools/build_rbxlx.py          # src/ -> build/ChronoDrill.rbxlx
python3 tools/make_sfx.py             # заново синтезировать звуки и музыку (build/SFX)
```
Папка `src/` совместима с Rojo (`*.server.lua`, `*.client.lua`, `*.lua`), если удобнее работать через него.

## Гача-петы как модели

Сервер собирает всех питомцев в `ReplicatedStorage.Assets.Pets` при старте. Хотите доработать модели руками:
запустите Play, скопируйте `ReplicatedStorage.Assets`, остановите игру, вставьте папку обратно в ReplicatedStorage —
AssetForge не перезаписывает модели, которые уже лежат на месте, и будет использовать ваши.
